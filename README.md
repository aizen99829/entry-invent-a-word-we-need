**TABNESIA** — the instant amnesia of opening a new browser tab and forgetting why before it even finishes loading. We all open tabs with a purpose, and we all watch that purpose evaporate somewhere between the click and the page load; this word finally gives that tiny daily defeat a name, so the next time it happens you can just sigh, say "tabnesia again," and open a new tab to forget about it.

## Run

```sh
node main.ts
```
